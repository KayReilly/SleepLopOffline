SleepLog Offline — инструкция

ВАЖНО:
• Записи хранятся в localStorage браузера на этом устройстве, а не в SQLite на компьютере.
• Интернет и компьютер не нужны после первого успешного открытия/установки PWA и кеширования файлов.
• На iPhone Service Worker и установка PWA требуют HTTPS (исключение — localhost, но на iPhone localhost означает сам телефон). Адрес компьютера вида http://192.168.x.x не является надёжным способом установки офлайн-PWA на iPhone.
• Эти файлы нужно один раз разместить на HTTPS-хостинге, например GitHub Pages. После первого открытия приложения онлайн дождитесь загрузки, затем добавьте на экран «Домой» и откройте установленное приложение хотя бы один раз с интернетом. Проверьте офлайн-режим после этого.
• Не очищайте данные Safari для сайта, иначе локальные записи могут удалиться. Используйте «Экспорт» для резервной копии JSON.

Файлы:
index.html             главная страница
static/style.css       оформление
static/app.js          логика и локальное хранение записей
manifest.json          настройки установки PWA
sw.js                  кеширование приложения для офлайн-режима
static/icon.svg        иконка

Публикация через GitHub Pages:
1. Создайте репозиторий на GitHub и загрузите содержимое этой папки в корень репозитория (index.html должен лежать в корне).
2. В репозитории откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку main и папку /(root), нажмите Save.
5. Дождитесь появления HTTPS-ссылки вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/.
6. Откройте эту ссылку в Safari на iPhone, дождитесь загрузки страницы.
7. Нажмите «Поделиться» → «На экран Домой» (если доступен переключатель «Открывать как веб-приложение», включите его) → «Добавить».
8. Откройте SleepLog с нового значка, пока интернет ещё есть. Затем включите авиарежим и проверьте, что приложение открывается и позволяет создать тестовую запись.
9. После проверки удалите тестовую запись.

Данные и ограничения:
• История отдельно на каждом устройстве, автоматической синхронизации нет.
• Записи сохраняются в хранилище браузера. Экспортируйте резервную копию регулярно.
• Приложение не передаёт записи в сеть. Service Worker скачивает только файлы интерфейса.
• Если офлайн-открытие не работает, вернитесь в Safari онлайн, откройте страницу ещё раз, подождите несколько секунд и повторите проверку.
